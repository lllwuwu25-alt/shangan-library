# 私钥备份操作清单

完成根密钥初始化后，按顺序执行：

- [ ] 在签发工具的“密钥管理”中输入 `我已知晓私钥风险`。
- [ ] 导出 `shangan-root-key-backup.private.key`。
- [ ] 将备份存入加密的离线介质。
- [ ] 再制作一份物理位置独立的加密副本。
- [ ] 确认两份备份都没有进入 Git、公开网盘或聊天记录。
- [ ] 在隔离环境完成一次恢复演练。
- [ ] 导出公钥并比对恢复前后结果完全一致。
- [ ] 用恢复后的密钥签发测试授权，并通过客户验签测试。

## 日常检查

- 正式签发前确认 Key ID 为 `primary-2026`。
- 只在受控开发者设备运行签发工具。
- 订单备注使用内部订单号，不填写姓名、手机号、微信聊天内容等敏感信息。
- 不截图、复制或记录私钥文件正文。
- 发现私钥疑似泄露时立即停止签发和发布，先制定密钥轮换与客户升级方案。
