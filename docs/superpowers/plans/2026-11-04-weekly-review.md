# Weekly Review Implementation Plan

**Goal:** 用户自选提醒日，首次打开询问是否回顾上一完整自然周；确认后生成并保存本地 AI 学习周报。

**Architecture:** 本地统计与提醒判断使用纯函数；周报数据进入既有 AppData 持久化和备份链；复用现有 AI 传输层，默认关闭，不自动发请求。

**Tech Stack:** React、TypeScript、Zustand、localStorage、现有 Modal 和兼容 Chat Completions 接口。

**Spec:** 用户本轮确认的可选每周回顾规则，包括同周错过提醒日后补提醒、历史报告、必要摘要传输与失败重试。

## Tasks
- [x] 本地周区间、摘要和提醒判断：测试周一/周日、跨年、本地时区、休息排除、缺失及非法数据、24 小时稍后提醒与本周跳过。
- [x] 数据结构、旧数据归一化、保存/删除/提醒操作，备份导入导出与清空兼容；密钥不进入周报。
- [x] AI 生成接口：仅传本地计算的摘要，明确统计口径，取消/失败不保存，不渲染模型 HTML。
- [x] 设置开关与提醒日、上周回顾手动入口、历史列表、报告详情；启动询问、确认传输、加载/错误/重试与停止等待。
- [x] 单测、lint、build 与隔离浏览器验收，确认关闭零请求、去重、跨周、补提醒、重启和备份恢复。

## Constraints
- 暂不封包、不发布，不删除既有学习数据。
- 仅关注最新一周，不批量补生成更早漏报；自选提醒日前不自动弹窗。
- “稍后”延迟 24 小时，“本周跳过”按被回顾的周区间去重。
- 实际专注仅统计已保存的专注记录；无记录不估算；完成情况以生成时本地任务状态为准。
- 仅发送每日、科目、计划完成与专注汇总，不发送任务题干、附件、错题或 API 密钥。
