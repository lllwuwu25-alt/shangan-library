# AI Study Assistant Implementation Plan

**Goal:** 通过多轮对话生成可编辑的学习计划草稿，经明确确认后写入统一任务数据。

**Architecture:** 复用现有 AI 配置和传输。模型返回文本与可选任务数组，不具备写操作。客户端验证草稿并批量追加到 tasks，其他页面按原有日期规则读取。

**Tech Stack:** React、TypeScript、Zustand、现有 Chat Completions 兼容通道。

**Spec:** 用户确认的“对话 → 草稿 → 确认加入”，先支持本周与下周计划新增，不改删原数据，不封包。

- [x] 测试并实现结构化响应、草稿校验、日期与重复检测、最少数据请求。
- [x] 增加桌面和手机入口、对话/停止等待、草稿编辑与批量写入。
- [x] 验证配置关闭零请求、多轮修订、确认前零写入、刷新持久化及首页/计划/番茄钟同步。

对话和未确认草稿仅驻留当前应用会话。发送时仅包含近期对话、当前草稿、日期范围和科目、时段选项。

验证：68 项单测、lint、构建、授权发布边界检查通过。隔离浏览器验证了 1440px 和 360px 下的导航、限流重试、停止等待、草稿编辑、确认新增、跳过重复、跨页面同步与刷新持久化。AI 请求使用模拟接口；未调用真实模型，未发布安装包。
