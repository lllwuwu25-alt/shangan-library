## 正式授权验收

使用开发者在独立签发工具中手动初始化的正式授权体系，生成一条非客户验收授权。验收过程未通过命令行输出、日志或 Git 传递授权码。

1. 客户桌面应用在缺少授权时显示激活页。
2. 粘贴正式验收授权后，本机离线校验成功并进入应用。
3. 完全退出并重新启动客户应用后，直接进入系统，证明授权文件被重新读取和验证。
4. 移除设备授权后，授权文件消失，应用返回激活页。
5. 移除前后业务数据项长度均为 1,851,674 字节，SHA-256 摘要完全一致，证明学习数据未被删除或改写。
