# Android 手机体验预览

## 本轮范围

- 保留底部五个常用入口；顶部更多菜单提供设置和联系我们。
- 手机页面只保留顶部导航标题，隐藏重复的页面标题和介绍卡片；桌面介绍保持不变。
- 学习计划以单日为主，可切换本周、下周；新增计划使用可滚动的底部表单。
- 资料库在手机上使用紧凑列表、树形目录选择器和触摸操作菜单，不使用拖拽排序。目录按父子关系排列并缩进，默认展开，可收起；搜索子目录时保留祖先路径，不改变原有折叠状态。
- 手机文件预览使用全屏弹窗；图片可切换原始大小，PDF 使用随安装包提供的 PDF.js 逐页渲染，Word `.docx` 和 Excel 保留完整内容滚动查看。
- 番茄钟优先展示计时，设置收起；长时间计时和横屏全屏布局适配。
- 表单提供至少 44px 的常用触控尺寸；键盘出现时隐藏底部导航，弹窗随可视高度调整。
- Android 返回键优先收起键盘、关闭弹窗、退出全屏或返回上级目录，再进行页面返回。

## 数据与授权边界

本轮不修改存储键、数据格式、Android applicationId，也不执行数据清理。正式更新能否覆盖安装，还需要保持既有签名密钥并递增 Android versionCode；卸载或系统清除应用数据仍会删除本地数据。

桌面 Tauri 商业授权保持不变。后续安卓授权接入已直接复用桌面 Rust 验签、公钥和存储源码，正式手机运行时要求激活，沿用已有有效 SL1 授权码。详情见 `ANDROID_LICENSE.md`。当前 GitHub APK 流程仍生成 debug 签名测试版，正式签名发布需要保持固定签名密钥。

网页预览和 Android 安装版各自存储数据，不自动同步。测试使用独立浏览器上下文和内存生成的测试附件，不读取或清空使用者数据。测试截图位于被 Git 忽略的 `.codex-tmp/mobile-qa/`，不会进入构建产物。

## 本地验证

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 5173
```

电脑打开 `http://127.0.0.1:5173`。手机与电脑连接同一局域网后，使用终端显示的 Network 地址。网页预览不是 APK，也不包含原生返回键事件。

```sh
npm run lint
npm test
npm run build
npm run test:mobile
npx cap sync android
```

`test:mobile` 默认使用本机 Google Chrome，可通过 `PLAYWRIGHT_CHANNEL` 改用其他已安装的 Chromium 通道。回归涵盖窄屏、横屏、桌面无横向溢出，日期计划隔离与持久化，目录操作，计时自动记录，PDF 最后一页渲染，长 Word/Excel 滚动、工作表切换，模拟键盘视口缩小和夜间弹窗。

GitHub Actions 可通过 `android-v*` 标签生成手机测试安装包，并发布为 Android 预发布下载，不替换桌面正式版。实际安卓机的键盘、返回手势、状态栏安全区域、系统文件选择器、后台计时、授权和覆盖升级仍需真机验收，浏览器模拟不能替代这些检查。
