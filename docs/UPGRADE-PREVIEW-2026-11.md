# 交互升级预览

本轮仅交付本地预览，不发布安装包。保留现有数据和授权机制。

## 范围

1. 桌面导航可折叠，图标有名称提示，偏好独立保存；手机导航不变。
2. 资料库新增树形思维导图，复用现有节点，支持平移、缩放、分支折叠、打开资料。不通过画布拖动修改文件归属。
3. AI 默认关闭，预填 DeepSeek 官方地址 `https://api.deepseek.com` 和 `deepseek-flash` 模型，密钥由用户填写；保留自定义兼容 Chat Completions 接口。新默认值不覆盖已有自定义配置，仅迁移未使用的旧空白占位。显式切换服务预设时，不沿用其他服务的密钥。支持 HTTPS 服务、本机 HTTP 服务。浏览器需要服务允许跨域；桌面和 Android 通过原生网络层请求。
4. 错题录入、核对、保存与复习分离。人工录入始终可用。图片识别仅提取所选 PNG/JPEG/WebP，不扫描资料库，不自动保存，不推测缺失答案。PDF/Word/Excel 继续支持附件，但本轮不做整份文档 AI 识别。

## 数据边界

AI 配置存于独立本地键。密钥默认仅当前进程有效，勾选记住后明文保存在本机，普通备份不包含此键。用户点击识别并确认后才发送选中截图。连接测试只发送测试文本。服务失败、取消或超时不保存错题。模型输出以纯文本显示，经过字段校验，用户核对后明确保存。

## 验证

- 单测覆盖地址、密钥保留、AI 关闭零请求、识别结果校验和取消。
- 浏览器隔离上下文验证导航折叠持久化、思维导图交互、错题创建/修改/复习/删除和 AI 请求模拟。
- 检查桌面与手机不出现整页横向溢出，运行 lint、build、单测及桌面 Rust 检查。
- 不使用真实客户密钥、不向外部模型发送真实学习资料；真实模型兼容性仍需用户以自己的服务验收。

协议参考：[Chat Completions API](https://developers.openai.com/api/reference/resources/chat)。只实现兼容协议，并不保证所有厂商私有 API 可直接使用。

DeepSeek 预设参考：[官方快速开始](https://api-docs.deepseek.com/)及[图片输入文档](https://api-docs.deepseek.com/guides/vision/)，核对日期 2026-11-04。不包含内置密钥；真实服务调用需用户自行验收。
